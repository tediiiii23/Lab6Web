    Pertanyaan Evaluasi

    Jawaban ketujuh soal berdasarkan dasar teori dan hasil praktik.

    04 / 04
    1. Apa yang dimaksud dengan DOM dan manfaatnya?

    DOM (Document Object Model) adalah representasi struktur HTML sebagai objek yang dapat diakses JavaScript. DOM memungkinkan program membaca dan mengubah teks, atribut, kelas CSS, serta menambahkan elemen dan merespons interaksi pengguna tanpa menulis ulang halaman.

    2. Perbedaan getElementById(), querySelector(), dan querySelectorAll()?

    getElementById('judul') memilih elemen berdasarkan ID; querySelector('.item') memilih kecocokan pertama dari selector CSS; dan querySelectorAll('.item') menghasilkan kumpulan semua elemen yang cocok (NodeList).

    3. Apa fungsi addEventListener() dan tiga contoh event?

    addEventListener() memasang fungsi penanganan ketika suatu event terjadi. Contohnya click saat tombol diklik, input saat isi kolom berubah, dan submit saat form dikirim. Contoh lain ialah change.

    4. Mengapa memakai event.preventDefault() pada submit?

    Karena perilaku default submit adalah mengirim form dan dapat memuat ulang atau berpindah halaman. event.preventDefault() menunda perilaku tersebut agar validasi JavaScript dijalankan dahulu dan pesan bisa ditampilkan.

    5. Perbedaan textContent dan innerHTML beserta keamanannya?

    textContent memperlakukan masukan sebagai teks biasa, sehingga tag HTML tidak dieksekusi. innerHTML membaca atau mengubah markup HTML; jangan memasukkan teks pengguna tak tepercaya ke dalamnya karena berisiko injeksi HTML atau XSS.

    6. Bagaimana classList.toggle() mengubah tampilan?

    classList.toggle('highlight') menambahkan kelas jika belum ada dan menghapusnya bila sudah ada. Aturan CSS kelas itu langsung memengaruhi tampilan, seperti pada latihan 3 dan eksperimen 4.

    7. Minimal tiga skenario pengujian validasi form?

    Contohnya (1) semua kolom kosong → pesan nama wajib diisi; (2) nama kurang dari 3 karakter → ditolak; (3) email tidak valid → ditolak; (4) usia 16 → ditolak; dan (5) nama, email, usia valid → sukses.
